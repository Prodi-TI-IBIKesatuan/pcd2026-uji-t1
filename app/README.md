# Demo Deteksi dan Pengenalan Pelat Nomor Kendaraan

Unggah foto kendaraan, tampilkan kotak pelat dan teks yang terbaca.

Folder ini diunggah apa adanya ke Hugging Face Spaces (SDK Gradio, hardware CPU basic). Bagian di antara tanda `---` di atas dibaca Spaces sebagai pengaturan; jangan dihapus.

1. Ganti isi fungsi `proses()` di `app.py` dengan metode terbaik kelompok.
2. Salin fungsi yang dibutuhkan dari notebook ke `app.py` (atau ke berkas `.py` baru di folder ini). Space tidak bisa membaca notebook atau Google Drive.
3. Tambahkan pustaka yang dipakai ke `requirements.txt` di folder ini.
4. Simpan ≤ 10 gambar contoh tersensor di `contoh/`; gambar itu muncul sebagai contoh yang bisa diklik.
